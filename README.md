# opac012
autonomous solution of a problem in algebraic combinatorics

This repo contains the results and prompting transcipts for a solution to [OPAC-012](https://realopacblog.wordpress.com/2019/09/30/matrix-counting-over-finite-fields/), which in turn is based on conjectures of [Lewis and Morales](https://arxiv.org/abs/1707.08192) (and others).

The solution and initial writeup were done entirely by Claude (Fable-5.1), with minimal human prompting and direction (see transcript).  The bulk of the work was done in about 90 minutes on September 8, 2026.  A second round of refereeing was done by ChatGPT-6 (Astra), along with some simplifications in the proof and improvements to the exposition; this is the final version presented as `opac012-solution.{tex,pdf}`.

Supplementary code is stored in the supplements folder.
